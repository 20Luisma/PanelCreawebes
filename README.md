# Panel_Creawebes

Proyecto creado con Monster Project Manager usando Clean Architecture.

## 🚀 Cómo Empezar
1. Clonar este repositorio.
2. Instalar dependencias según el stack.
3. `cp .env.example .env` y completar las claves reales.
4. Levantar el entorno de desarrollo local.

---

### 🧠 Modo Nivel Dios (Infraestructura IA)
- `/load_context`: Inyectar memoria y reglas a la IA.
- `/save_context`: Extraer trabajo y backup del estado.
- `/clean_context`: Limpiar y compactar el historial.
- `/analizar_escalabilidad`: Auditoría técnica profunda.
